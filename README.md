> Тестовая версия. ليل (layl) — по-арабски «ночь», коллекция «حرية» — «свобода».

## Возможности

- **Каталог** с фильтром: худи, штаны, футболки
- **Карточка товара**: размеры XS–XL, количество
- **Корзина** сохраняется в браузере
- **Оформление без регистрации**: имя, телефон, город, доставка, адрес, комментарий
- **Заказ в WhatsApp** — чат открывается с готовым текстом заказа
- **Заказ в Telegram** — текст заказа копируется, открывается чат
- **Валюты**: ₸ / $ / € / ₽ — цены хранятся в тенге и пересчитываются по курсу
- **Тема**: как в системе, светлая или тёмная
- **9 языков**: русский, қазақша, English, italiano, deutsch, français, español, türkçe, العربية (с зеркальной вёрсткой). Язык определяется по браузеру, его можно сменить в шапке или ссылкой `?lang=en`
- Адаптивная вёрстка (телефон → большой экран), доступность с клавиатуры

## Настройка

Всё меняется в одном файле — [`js/config.js`](js/config.js):

| Что | Поле |
|---|---|
| Номер WhatsApp | `whatsappNumber` |
| Telegram | `telegramUsername` |
| Курсы валют | `currencies` (сколько тенге за 1 единицу) |
| Товары, цены (в тенге), размеры, фото | `products` |
| Тексты и переводы | [`js/i18n.js`](js/i18n.js) |

Фото товаров кладите в папку `img/`.

## Дальше: Telegram-бот

Укажите `orderWebhookUrl` в `config.js` — каждый заказ будет дополнительно отправляться POST-запросом JSON:

```json
{
  "id": "L261111-AB12",
  "createdAt": "2026-11-11T14:00:00.000Z",
  "channel": "whatsapp",
  "customer": { "name": "", "phone": "", "city": "", "address": "", "delivery": "", "comment": "" },
  "items": [{ "id": "hurriya-hoodie", "name": "Hurriya Hoodie", "size": "M", "qty": 1, "price": 14990 }],
  "total": 14990, "currency": "KZT",
  "displayCurrency": "EUR", "displayTotal": 30
}
```

Бот (например, на Supabase Edge Function или Cloudflare Worker) принимает JSON, сохраняет заказ и присылает уведомление в Telegram.

## Структура

```
index.html        страница
css/styles.css    стили, светлая и тёмная темы
js/config.js      настройки и товары
js/i18n.js        переводы на 9 языков
js/app.js         каталог, корзина, языки, валюты, тема, заказ
img/              фото товаров и логотип
DESIGN.md         разбор стиля-референса
```

Без сборки и зависимостей — обычный статический сайт, хостится на GitHub Pages.
